TP final : Gestion complète d’un projet 
avec Git 
Objectifs du TP 
Ce TP a pour objectif de vérifier votre capacité à utiliser Git de manière autonome dans le cadre 
d’un projet. 
• Créer et versionner un projet depuis zéro 
• Construire un historique cohérent 
• Utiliser des branches et fusionner des évolutions 
• Analyser l’historique du projet 
• Corriger et annuler des modifications ou des commits 
• Mettre temporairement du travail de côté 
• Récupérer une modification précise provenant d’une autre branche 
• Gérer les versions du projet et les fichiers à ignorer
